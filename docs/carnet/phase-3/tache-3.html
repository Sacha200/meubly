Tâche 3 : l'adaptateur Shopify

Lire le catalogue de Connox et de Fleux, deux boutiques Shopify, et en sortir un article normalisé par variante : marque, titre, EAN, prix, disponibilité, images.

PR #29 feat/ingestion-shopify 25 nov. 2026

Objectif

Un adaptateur traduit le site d'un marchand en articles au même format pour tous. La suite de la collecte (rapprochement, écriture en base) ne connaît que ce format et ignore d'où viennent les données. Shopify a l'avantage d'exposer deux adresses publiques en JSON :

  • /products.json?limit=250&page=N : le catalogue, 250 produits par page. Pas d'EAN, prix en euros sous forme de texte.
  • /products/<poignée>.js : le détail d'un produit, avec le barcode. Prix en centimes.

Toutes les requêtes passent par fetchText, qui sera en pratique le createPoliteFetch de la tâche 2 : agent déclaré, robots.txt, 2 secondes entre deux pages.

Étapes

  1. FixturesCinq fichiers JSON tirés des vraies fiches du spike, générés plutôt que tapés.
  2. Le test shopify.test.jsDix cas, du plus simple (l'adaptateur est enregistré) aux cas limites (clé fausse, EAN-8, page inchangée).
  3. Les modulesadapters/index.js (liste des adaptateurs et contrat), adapters/shopify.js.
  4. Vérification150 tests verts, lint sans erreur, format conforme.

Le contrat

Tout adaptateur expose deux fonctions :

  • listBrands(ctx)Rend l'ensemble des marques vendues, normalisées par normText. Sert à trouver les marques communes à plusieurs marchands.
  • listItems(ctx, brands)Rend, une par une, les variantes des produits de ces marques, au format ScrapedItem.
  • ctx.configLe contenu de partner.adapter_config en base, par exemple { "baseUrl": "https://www.connox.fr", "stripBrandPrefix": true }.
  • ctx.knownPagesLes pages déjà lues, avec leur date de modification et leurs EAN. Une page inchangée n'est pas relue.

shopify.js

meubly-back/ingestion/adapters/shopify.js 
// Adaptateur Shopify (Connox, Fleux) : catalogue par /product.json, detail par /products/<handle>.js.
import { pickGtin } from "../gtin.js";
import { normText } from "../text.js";

const MAX_PAGES = 200; // garde-fou : 50 000 produits
const MAX_IMAGES = 6;
const MAX_DESCRIPTION = 900;
const AVAILABILITY = { true: "in_stock", false: "out_of_stock" };
const ENTITIES = { amp: "&", lt: "<", gt: ">", quot: '"', apos: "'", nbsp: " " };

/**Pages de /products.json, jusqu'a la premiere vide. */
async function* catalogPages({ config, fetchText }) {
    for (let page = 1; page <= MAX_PAGES; page++) {
        const url =
            `${config.baseUrl}/products.json?limit=250&page=${page}`;
        const { products } = JSON.parse(await fetchText(url));
        if (!products.length) return;
        yield products;
    }
}

/** Resume /products.json : prix en euros (texte), pas de barcode. */
function fromSummary(product) {
    return {
        ...product,
        type: product.product_type,
        description: product.body_html,
        updateAt: product.updated_at,
        images: product.images.map((image) => image.src),
        variants: product.variants.map((v) => ({
            ...v,
            priceCents: Math.round(Number(v.price) * 100),
            image: v.featured_image?.src,
        })),
    };

    /** EAN-13, 14 ou 12 avant EAN-8 : une reference de 8 chiffres passe la cle 1 fois sur 10. */
    function findGtin(...candidates) {
        const long = candidates.filter((candidate) => String(candidate ?? "").trim().length >= 12);
        return pickGtin(...long) ?? pickGtin(...candidates);
    }

    function stripBrandPrefix(title, brand) {
        const prefix = `${brand} -  `.toLowerCase();
        return title.toLowerCase().startsWith(prefix) ?
            title.slice(prefix.length) : title;
    }

    const absolute = (src) => (src.startsWith("//") ? `https:${src}` : src);

    /** Texte brut : balises retirees, entites decodees, espaces reduits. */
    function plainText(html) {
        //shortcut: entites courantes et decimales seulement, ajouter &#x..; si un marchand en sert
        const text = String(html ?? "")
            .replace(/<[^>]*>/g, " ")
            .replace(/&(#\d+|[a-z]+);/gi, (match, entity) =>
                entity.startsWith("#")
                    ? String.fromCodePoint(Number(entity.slice(1)))
                    : (ENTITIES[entity.toLowerCase()] ?? match)
            )
            .replace(/\s+/g, " ")
            .trim();
        return text ? text.slice(0, MAX_DESCRIPTION) : null;
    }

    /** Une page produit normalisee -> un ScrapedItem par variante. */
    function* toItems(config, page, knownGtins) {
        for (const variant of page.variants) {
            const externalId = String(variant.id);
            const barcode = String(variant.barcode ?? "").trim();
            const gtin = knownGtins ? (knownGtins[externalId] ?? null) :
                findGtin(barcode, variant.sku);
            yield {
                externalId,
                pageId: String(page.id),
                pageUpdatedAt: page.updateAt ?? null,
                url:
                    `${config.baseUrl}/products/${page.handle}?variant=${externalId}`,
                brand: page.vendor,
                productTitle: config.stripBrandPrefix
                    ? stripBrandPrefix(page.title, page.vendor)
                    : page.title,
                variantLabel: variant.title === "Default Title" ? "" : variant.title,
                gtin,
                manufacturerRef: barcode && barcode !== gtin ? barcode : null,
                price: variant.priceCents / 100,
                availability: AVAILABILITY[variant.available] ?? "unknown",
                images: [...new Set([variant.image, ...page.images].filter(Boolean).map(absolute))].slice(
                    0,
                    MAX_IMAGES
                ),
                description: plainText(page.description),
                attributes: {},
                weightKg: variant.grams > 0 ? variant.grams / 1000 : null,
                categoryHint: page.type || null,
            };
        }
    }

    /** @type {import} */

}
  • catalogPagesGénérateur asynchrone (async function*) : il rend les pages du catalogue l'une après l'autre et s'arrête à la première vide. MAX_PAGES évite une boucle sans fin si un marchand ne renvoyait jamais de page vide.
  • fromDetail / fromSummaryLes deux sources ne décrivent pas un produit de la même façon : prix en centimes ou en euros texte, weight ou grams, type ou product_type. Chacune est ramenée au même format pour qu'une seule fonction fabrique les articles.
  • Math.round(… * 100)Number("239.00") * 100 peut donner 23899.999… à cause des nombres à virgule flottante. L'arrondi remet un entier juste.
  • findGtinCherche d'abord un code de 12 chiffres ou plus. Une référence de 8 chiffres passe la clé de contrôle une fois sur 10 par hasard et serait prise pour un EAN-8.
  • manufacturerRefLe barcode, quand il n'est pas l'EAN. Chez Fleux, le barcode contient la référence fabricant et l'EAN est rangé dans sku.
  • stripBrandPrefixConnox écrit « HAY - Pouf Planar ». Le préfixe est retiré quand la configuration du marchand le demande, sans tenir compte des majuscules.
  • plainTextRetire les balises HTML, décode les entités (&#039; devient une apostrophe), réduit les espaces, coupe à 900 caractères.
  • imagesL'image de la variante d'abord, puis celles de la page, sans doublon (new Set), 6 au plus. Les adresses //cdn… reçoivent https:.
  • AVAILABILITYUne table au lieu de deux conditions imbriquées : true donne en stock, false épuisé, une valeur absente donne « unknown ».
  • knownPagesSi updated_at n'a pas changé, on ne demande pas le .js : l'article est construit depuis products.json et l'EAN est repris de la collecte précédente. Limite assumée : la référence fabricant reste vide dans ce cas.
  • compare_at_priceLe prix barré du marchand n'est jamais repris (choix de la spec). L'article ne contient aucune clé qui s'en approche.

Le test

makeCtx fabrique un contexte dont le réseau sert les fixtures selon l'URL demandée. Une URL inattendue fait échouer le test, ce qui prouve qu'aucune requête superflue ne part. hayWith modifie une variante de la fiche HAY pour tester un cas limite sans créer une fixture de plus.

import { describe, it, expect, vi } from "vitest";
import { readFileSync } from "node:fs";
import { adapters } from "../../../ingestion/adapters/index.js";
import { shopify } from "../../../ingestion/adapters/shopify.js";

const BASE = "https://shop.test";
const HAY_JS = `${BASE}/products/hay-pouf-planar.js`;
const fixture = (name) =>
  readFileSync(new URL(`../../fixtures/ingestion/shopify/${name}`, import.meta.url), "utf8");
const ROUTES = {
  [`${BASE}/products.json?limit=250&page=1`]: "products-page1.json",
  [`${BASE}/products.json?limit=250&page=2`]: "products-page2.json",
  [HAY_JS]: "product-connox.js.json",
  [`${BASE}/products/thonet-s-285-1-bureau.js`]: "product-connox-default.js.json",
  [`${BASE}/products/lampe-de-table-apex.js`]: "product-fleux.js.json",
};

/** Contexte d'adaptateur dont le reseau sert les fixtures ; `override` remplace une reponse. */
function makeCtx({ config = {}, override = {}, knownPages } = {}) {
  const fetchText = vi.fn(async (url) => {
    if (url in override) return JSON.stringify(override[url]);
    if (!ROUTES[url]) throw new Error(`URL inattendue : ${url}`);
    return fixture(ROUTES[url]);
  });
  return {
    config: { baseUrl: BASE, stripBrandPrefix: true, ...config },
    fetchText,
    knownPages,
  };
}

async function collect(ctx, brands) {
  const items = [];
  for await (const item of shopify.listItems(ctx, new Set(brands))) items.push(item);
  return items;
}

const item = (items, externalId) => items.find((i) => i.externalId === externalId);
const jsCalls = (ctx) =>
  ctx.fetchText.mock.calls.map(([url]) => url).filter((u) => u.endsWith(".js"));

/** Fiche Connox HAY modifiee pour un cas limite */
function hayWith(changeVariant) {
  const detail = JSON.parse(fixture("product-connox.js.json"));
  changeVariant(detail.variants[0]);
  return { [HAY_JS]: detail };
}

describe("adaptateur shopify", () => {
  it("est enregistre sous la cle shopify", () => {
    expect(adapters.shopify).toBe(shopify);
  });

  it("listBrands lit le catalogue jusqu'a une page vide et normalise les marques", async () => {
    const ctx = makeCtx();
    expect(await shopify.listBrands(ctx)).toEqual(new Set(["hay", "thonet", "liewood"]));
    expect(ctx.fetchText).toHaveBeenCalledTimes(2);
  });

  it("ne lit en .js que les produits des marques demandees", async () => {
    const ctx = makeCtx();
    const items = await collect(ctx, ["hay"]);
    expect(jsCalls(ctx)).toEqual([HAY_JS, `${BASE}/products/lampe-de-table-apex.js`]);
    expect(items).toHaveLength(5);
  });

  it("produit Connox : titre sans marque, prix en euros, EAN du barcode", async () => {
    const sable = item(await collect(makeCtx(), ["hay"]), "57814168338776");
    expect(sable).toMatchObject({
      pageId: "15899599700312",
      url: `${BASE}/products/hay-pouf-planar?variant=57814168338776`,
      brand: "HAY",
      productTitle: "Pouf Planar",
      variantLabel: "sable",
      gtin: "5710441309116",
      manufacturerRef: null,
      price: 239,
      availability: "in_stock",
      weightKg: 4.2,
      categoryHint: "Möbel",
    });
    expect(sable.images[0]).toMatch(/sand\.jpg/);
    expect(sable.images.every((src) => src.startsWith("https://"))).toBe(true);
    expect(sable.description).toContain("chambre d'enfant");
    expect(sable.description).not.toMatch(/[<>]/);
  });

  it("variante unique : libelle vide, prix barre absent", async () => {
    const [bureau] = await collect(makeCtx(), ["thonet"]);
    expect(bureau.variantLabel).toBe("");
    expect(bureau.price).toBe(5553.05);
    expect(Object.keys(bureau).filter((key) => /compare/i.test(key))).toEqual([]);
  });

  it("produit Fleux : EAN dans sku, reference fabricant dans barcode", async () => {
    const items = await collect(makeCtx({ config: { stripBrandPrefix: false } }), ["hay"]);
    expect(item(items, "47561977528654")).toMatchObject({
      productTitle: "Lampe de table Apex",
      gtin: "5710441326304",
      manufacturerRef: "AD343-A687",
      price: 125,
    });
  });

  it("refuse un barcode de 13 chiffres a cle fausse", async () => {
    const override = hayWith((v) => (v.barcode = "5710441309117"));
    const items = await collect(makeCtx({ override }), ["hay"]);
    expect(item(items, "57814168338776").gtin).toBeNull();
  });

  it("prefere un EAN-13 a un code de 8 chiffres valide par hasard", async () => {
    const override = hayWith((v) => {
      v.barcode = "96385074";
      v.sku = "5710441309116";
    });
    const sable = item(await collect(makeCtx({ override }), ["hay"]), "57814168338776");
    expect(sable).toMatchObject({ gtin: "5710441309116", manufacturerRef: "96385074" });
  });

  it("marque une variante indisponible", async () => {
    const override = hayWith((v) => (v.available = false));
    const items = await collect(makeCtx({ override }), ["hay"]);
    expect(item(items, "57814168338776").availability).toBe("out_of_stock");
  });

  it("page inchangee : pas de .js, EAN repris de knownPages", async () => {
    const knownPages = new Map([
      [
        "15899599700312",
        {
          updatedAt: "2026-11-20T10:00:00+01:00",
          gtins: { 57814168338776: "5710441309116", 57814168469848: null },
        },
      ],
    ]);
    const ctx = makeCtx({ knownPages });
    const items = await collect(ctx, ["hay"]);
    expect(jsCalls(ctx)).not.toContain(HAY_JS);
    expect(item(items, "57814168338776")).toMatchObject({ gtin: "5710441309116", price: 239 });
    expect(item(items, "57814168469848").gtin).toBeNull();
  });
});
  • listBrandsDeux requêtes seulement : la page 1, puis la page 2 vide qui arrête la lecture.
  • marques demandéesAvec la marque « hay », seules les fiches HAY (Connox) et Hay (Fleux) sont lues en .js. « HAY » et « Hay » donnent la même marque une fois normalisées.
  • 5553.05Le bureau Thonet coûte 555 305 centimes. Le test vérifie la conversion exacte en euros.
  • clé fausseLe dernier chiffre de l'EAN est changé : l'article est gardé, mais sans EAN.
  • 96385074Un EAN-8 valide placé dans barcode, un EAN-13 dans sku : c'est l'EAN-13 qui doit l'emporter.
  • page inchangéeAucune requête .js pour la page HAY, et les EAN viennent de knownPages, y compris un null.

À retenir

  • Un format commun. Toutes les différences entre marchands restent dans l'adaptateur. La tâche 4 n'aura qu'un seul format à traiter.
  • Lire le moins possible. Le catalogue suffit pour savoir quoi relire, et une page inchangée n'est pas redemandée. C'est ce qui permet une collecte quotidienne polie.
  • Le 429 de Connox. À surveiller pour la collecte planifiée (tâche 13) : politeFetch attend une minute et réessaie trois fois, puis abandonne.
  • Hors périmètre : attributes reste vide (les noms d'options Shopify sont peu fiables, la couleur est déjà dans le libellé de variante), entités HTML hexadécimales non décodées.
  • Suite : tâche 4, rapprochement et écriture en base, avec la commande npm run ingest.
