Tâche 2 : le socle de collecte

Trois petits outils sur lesquels reposent tous les adaptateurs marchands : reconnaître un code EAN, normaliser un texte pour comparer des marques, et télécharger une page en respectant le marchand.

PR #27 mergée feat/ingestion-core commit b6b14df 25 nov. 2026

Objectif

Les tâches suivantes (adaptateurs Shopify et Nordic Nest) vont lire des milliers de fiches produit chez Connox, Fleux et Nordic Nest. Avant d'écrire la moindre ligne propre à un marchand, on pose trois briques communes :

  • Identifier un produit sans ambiguïté. Le même article porte le même EAN (le code-barres) chez tous les marchands. C'est la clé du rapprochement, encore faut-il ne garder que de vrais EAN.
  • Comparer des marques écrites différemment. « &Tradition », « &tradition » et « Tradition » doivent donner la même chose.
  • Rester un visiteur correct. Le robot se présente sous son vrai nom, lit robots.txt, ne va pas plus vite qu'une page toutes les 2 secondes par site, et s'arrête net s'il est refusé. Aucun contournement.

gtin.js

meubly-back/ingestion/gtin.js

Un EAN n'est pas n'importe quelle suite de chiffres : son dernier chiffre est une clé de contrôle calculée à partir des autres. Vérifier cette clé élimine les références fabricant, les fautes de saisie et les numéros internes que certains marchands rangent dans les mêmes champs.

/**
 * Vrai si la valeur est un GTIN (EAN-8, UPC-12, EAN-13, GTIN-14) dont la cle de controle est juste.
 * @param {unknown} value
 * @returns {boolean}
 */
export function isGtin(value) {
  if (typeof value !== "string" || !/^(\d{8}|\d{12,14})$/.test(value)) return false;
  const digits = [...value].map(Number);
  const check = digits.pop();
  const sum = digits
    .reverse()
    .reduce((total, digit, i) => total + digit * (i % 2 === 0 ? 3 : 1), 0);
  return (10 - (sum % 10)) % 10 === check;
}

/**
 * Premier candidat qui est un GTIN valide (les marchands rangent l'EAN dans barcode ou dans sku).
 * @param {...unknown} candidates
 * @returns {string | null}
 */
export function pickGtin(...candidates) {
  return candidates.map((candidate) => String(candidate ?? "").trim()).find(isGtin) ?? null;
}
  • /^(\d{8}|\d{12,14})$/Accepte 8, 12, 13 ou 14 chiffres, rien d'autre (pas de lettre, pas de tiret). Ce sont les longueurs EAN-8, UPC-12, EAN-13 et GTIN-14.
  • digits.pop()Retire le dernier chiffre : c'est la clé qu'on va recalculer et comparer.
  • reverse() + poids 3/1En partant de la droite, on multiplie les chiffres alternativement par 3 et par 1, puis on additionne. Partir de la droite permet d'utiliser la même règle pour toutes les longueurs.
  • (10 - sum % 10) % 10La clé est ce qu'il faut ajouter pour arriver à la dizaine suivante. Le second % 10 donne 0 quand la somme tombe déjà juste.
  • pickGtin(...candidates)Les marchands Shopify rangent l'EAN tantôt dans barcode, tantôt dans sku (Fleux). On essaie chaque champ, nettoyé par String(x ?? "").trim(), et on garde le premier valide, sinon null.

Sert à comparer deux marques ou deux titres sans être gêné par la casse, les accents ou la ponctuation.

/**
 * Texte comparable : minuscules, sans accents, sans "&", tout autre signe remplace par un espace.
 * @param {string} s
 * @returns {string}
 */
export function normText(s) {
  return s
    .toLowerCase()
    .normalize("NFD")
    .replace(/[\u0300-\u036f]/g, "")
    .replace(/&/g, "")
    .replace(/[^a-z0-9]+/g, " ")
    .trim();
}
  • normalize("NFD")Décompose chaque lettre accentuée en lettre + accent séparé : « é » devient « e » suivi d'un accent aigu.
  • [̀-ͯ]Cette plage Unicode contient les accents isolés. On les supprime, il ne reste que la lettre.
  • replace(/&/g, "")Le « & » est retiré sans laisser d'espace : « &Tradition » devient « tradition ».
  • [^a-z0-9]+ → " "Toute suite de caractères qui n'est ni lettre ni chiffre devient un seul espace, grâce au +. « Fritz Hansen » et « Fritz - Hansen » donnent tous deux « fritz hansen ».
  • trim()Enlève l'espace éventuel laissé au début ou à la fin.

politeFetch.js

meubly-back/ingestion/politeFetch.js

Le module le plus important. createPoliteFetch fabrique une fonction get(url) qui applique toutes les règles de politesse. Toute la collecte passera par elle : aucun adaptateur n'appelle fetch directement.

// Requetes "polies" vers les marchands : agent declare, robots.txt, 1 requete / 2 s par hote.
// Aucun contournement : un refus leve BlockedError et la collecte de ce marchand s'arrete.

const CHALLENGE_MARKERS = /captcha|datadome|cf-chl/i;
const RETRY_DELAY_MS = 60_000;
const MAX_RETRIES = 3;

export class BlockedError extends Error {
  constructor(message) {
    super(message);
    this.name = "BlockedError";
  }
}

export class HttpError extends Error {
  constructor(status, url) {
    super(`HTTP ${status} ${url}`);
    this.name = "HttpError";
    this.status = status;
  }
}

const defaultSleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

/** Regles Allow/Disallow pour PrixoliBot : son propre groupe s'il existe, sinon le groupe "*". */
function parseRobots(text) {
  const groups = [];
  let current = null;
  let lastWasAgent = false;
  for (const raw of text.split(/\r?\n/)) {
    const match = raw
      .replace(/#.*/, "")
      .trim()
      .match(/^([a-z-]+)\s*:\s*(.*)$/i);
    if (!match) continue;
    const key = match[1].toLowerCase();
    const value = match[2].trim();
    if (key === "user-agent") {
      if (!lastWasAgent) groups.push((current = { agents: [], rules: [] }));
      current.agents.push(value.toLowerCase());
      lastWasAgent = true;
    } else {
      lastWasAgent = false;
      if (current && value && (key === "allow" || key === "disallow")) {
        current.rules.push({ allow: key === "allow", path: value });
      }
    }
  }
  const own = groups.filter((group) => group.agents.includes("prixolibot"));
  const chosen = own.length ? own : groups.filter((group) => group.agents.includes("*"));
  return chosen.flatMap((group) => group.rules);
}

/** Motif robots.txt ("*" = n'importe quoi, "$" final = fin d'URL) en expression reguliere. */
function toRegex(pattern) {
  const escaped = pattern.replace(/[.+?^${}()|[\]\\]/g, "\\$&").replace(/\*/g, ".*");
  return new RegExp(`^${escaped.replace(/\\\$$/, "$")}`);
}

/** La regle la plus longue qui correspond l'emporte ; a egalite, Allow gagne. */
function isAllowed(rules, path) {
  let best = null;
  for (const rule of rules) {
    if (!toRegex(rule.path).test(path)) continue;
    const longer = !best || rule.path.length > best.path.length;
    const tieAllow = best && rule.path.length === best.path.length && rule.allow;
    if (longer || tieAllow) best = rule;
  }
  return !best || best.allow;
}

/**
 * Cree une fonction qui lit une URL marchande et renvoie son corps texte.
 * Rien ne part sur le reseau avant le premier appel.
 * @param {{ botUrl?: string, delayMs?: number, fetchImpl?: typeof fetch, sleep?: (ms: number) => Promise<void> }} [options]
 * @returns {(url: string) => Promise<string>}
 */
export function createPoliteFetch({
  botUrl = "https://github.com/Sacha200/meubly",
  delayMs = 2000,
  fetchImpl = fetch,
  sleep = defaultSleep,
} = {}) {
  const headers = { "User-Agent": `PrixoliBot/1.0 (+${botUrl})` };
  const visitedHosts = new Set();
  const robotsByOrigin = new Map();

  async function request(url) {
    const { host } = new URL(url);
    if (visitedHosts.has(host)) await sleep(delayMs);
    visitedHosts.add(host);
    return fetchImpl(url, { headers });
  }

  async function requestWithRetry(url) {
    for (let attempt = 0; ; attempt++) {
      const response = await request(url);
      if (response.status !== 429 || attempt === MAX_RETRIES) return response;
      await sleep(RETRY_DELAY_MS);
    }
  }

  async function robotsRules(origin) {
    if (!robotsByOrigin.has(origin)) {
      const response = await requestWithRetry(`${origin}/robots.txt`);
      robotsByOrigin.set(origin, response.ok ? parseRobots(await response.text()) : []);
    }
    return robotsByOrigin.get(origin);
  }

  return async function politeFetch(url) {
    const { origin, pathname, search } = new URL(url);
    if (!isAllowed(await robotsRules(origin), pathname + search)) {
      throw new BlockedError(`Interdit par robots.txt : ${url}`);
    }
    const response = await requestWithRetry(url);
    const body = await response.text();
    if (response.status === 403 || (body.length < 20_000 && CHALLENGE_MARKERS.test(body))) {
      throw new BlockedError(`Acces refuse (${response.status}) : ${url}`);
    }
    if (!response.ok) throw new HttpError(response.status, url);
    return body;
  };
}
  • BlockedError / HttpErrorDeux types d'erreur distincts. BlockedError veut dire « le marchand ne veut pas de nous » : la collecte de ce marchand s'arrête. HttpError est une panne ordinaire, qui porte le code status.
  • parseRobotsLit robots.txt ligne par ligne. Plusieurs lignes User-agent qui se suivent forment un seul groupe. Si un groupe vise prixolibot, lui seul s'applique, sinon c'est le groupe *.
  • toRegexTraduit un motif robots.txt en expression régulière : * = n'importe quoi, $ final = fin d'URL. Les autres caractères spéciaux sont échappés.
  • isAllowedParmi les règles qui correspondent, la plus longue (donc la plus précise) l'emporte. À longueur égale, Allow gagne. Sans règle correspondante, tout est autorisé.
  • Paramètres par défautfetchImpl et sleep sont injectables : les tests passent de faux réseaux et de fausses attentes, sinon chaque test durerait des minutes.
  • requestAvant chaque requête vers un hôte déjà visité, on attend delayMs (2 s). Le premier appel à un hôte part tout de suite.
  • requestWithRetrySur un 429 (« trop de requêtes »), on attend 60 s et on réessaie, 3 fois au plus. Le dernier 429 est renvoyé tel quel et finira en HttpError.
  • robotsRulesrobots.txt est lu une seule fois par site, puis gardé dans une Map. S'il est absent (404), la liste de règles est vide : tout est autorisé.
  • politeFetch(url)Ordre des contrôles : robots.txt d'abord (sans jamais appeler la page interdite), puis la requête, puis le refus (403, ou page courte contenant captcha, datadome ou cf-chl), puis tout autre statut non 2xx.
  • body.length < 20_000Une vraie fiche produit peut citer « captcha » dans un script. Une page de défi, elle, est courte. La limite évite les fausses alertes.

Les tests

Les tests de politeFetch remplacent le réseau par une fonction setup(routes) : chaque URL rend ses réponses dans l'ordre, une URL inconnue rend 404. sleep est un espion qui enregistre les attentes demandées, sans attendre réellement.

import { describe, it, expect, vi } from "vitest";
import { createPoliteFetch, BlockedError, HttpError } from "../../../ingestion/politeFetch.js";

const ROBOTS = "https://shop.test/robots.txt";
const PAGE = "https://shop.test/products/a";

/** Faux fetch : chaque URL rend ses reponses dans l'ordre ; une URL inconnue rend 404. */
function setup(routes) {
  const fetchImpl = vi.fn(async (url) => {
    const { status = 200, body = "" } = routes[url]?.shift() ?? { status: 404 };
    return new Response(body, { status });
  });
  const sleep = vi.fn(async () => {});
  const get = createPoliteFetch({ botUrl: "https://x.test", fetchImpl, sleep });
  return { get, fetchImpl, sleep };
}

describe("politeFetch", () => {
  it("se presente avec l'agent declare", async () => {
    const { get, fetchImpl } = setup({ [PAGE]: [{ body: "ok" }] });
    expect(await get(PAGE)).toBe("ok");
    expect(fetchImpl).toHaveBeenCalledWith(PAGE, {
      headers: { "User-Agent": "PrixoliBot/1.0 (+https://x.test)" },
    });
  });

  it("autorise tout quand robots.txt est absent (404)", async () => {
    const { get } = setup({ [PAGE]: [{ body: "ok" }] });
    expect(await get(PAGE)).toBe("ok");
  });

  it("refuse une URL interdite par robots.txt sans appeler la page", async () => {
    const forbidden = "https://shop.test/prive/a";
    const { get, fetchImpl } = setup({ [ROBOTS]: [{ body: "User-agent:*\nDisallow: /prive" }] });
    await expect(get(forbidden)).rejects.toBeInstanceOf(BlockedError);
    expect(fetchImpl).not.toHaveBeenCalledWith(forbidden, expect.anything());
  });

  it("attend 2 s entre deux requetes du meme hote (robots.txt compris)", async () => {
    const other = "https://shop.test/products/b";
    const { get, sleep } = setup({ [PAGE]: [{ body: "1" }], [other]: [{ body: "2" }] });
    await get(PAGE);
    await get(other);
    expect(sleep.mock.calls).toEqual([[2000], [2000]]);
  });

  it("reessaie apres 60 s sur un 429", async () => {
    const { get, sleep } = setup({ [PAGE]: [{ status: 429 }, { body: "ok" }] });
    expect(await get(PAGE)).toBe("ok");
    expect(sleep).toHaveBeenCalledWith(60000);
  });

  it("abandonne apres 3 nouvelles tentatives sur 429", async () => {
    const tooMany = { status: 429 };
    const { get, sleep } = setup({
      [PAGE]: [tooMany, tooMany, tooMany, tooMany],
    });
    const error = await get(PAGE).catch((e) => e);
    expect(error).toBeInstanceOf(HttpError);
    expect(error.status).toBe(429);
    expect(sleep.mock.calls.filter(([ms]) => ms === 60000)).toHaveLength(3);
  });

  it("leve BlockedError sur un 403", async () => {
    const { get } = setup({ [PAGE]: [{ status: 403 }] });
    await expect(get(PAGE)).rejects.toBeInstanceOf(BlockedError);
  });

  it("leve BlockedError sur une page de defi anti-robot", async () => {
    const { get } = setup({ [PAGE]: [{ body: "<html>cf-chl challenge</html>" }] });
    await expect(get(PAGE)).rejects.toBeInstanceOf(BlockedError);
  });

  it("leve HttpError avec le statut sur un 500", async () => {
    const { get } = setup({ [PAGE]: [{ status: 500 }] });
    const error = await get(PAGE).catch((e) => e);
    expect(error).toBeInstanceOf(HttpError);
    expect(error.status).toBe(500);
  });
});
  • agent déclaréVérifie l'en-tête exact PrixoliBot/1.0 (+https://x.test).
  • robots.txt absentAucune route n'est définie pour robots.txt, le faux réseau rend 404 : la page doit quand même être lue.
  • robots.txt interditnot.toHaveBeenCalledWith(forbidden, ...) prouve que la page interdite n'a jamais été demandée au marchand.
  • 2 s entre requêtesTrois requêtes vers le même site (robots.txt, page a, page b) donnent exactement deux attentes de 2 000 ms.
  • 429Un 429 puis un 200 : le corps est rendu après une attente de 60 000 ms. Quatre 429 d'affilée : abandon après 3 nouvelles tentatives.
  • 403, défi, 500Les deux premiers lèvent BlockedError, le troisième HttpError avec status === 500.

Corrections

Corrigé dans la PR #28

Après le merge de la PR #27, une relecture complète des tests a trouvé des écarts avec le code donné. Le code affiché sur cette page est la version corrigée.

  • Test sans effet. not.toHaveBeenNthCalledWith(forbidden, ...) attend un numéro d'appel en premier argument : avec une URL, il ne trouve aucun appel et le .not réussit toujours, même si la page interdite est téléchargée. Remplacé par not.toHaveBeenCalledWith.
  • Nom inversé. « autorise une URL interdite... » est devenu « refuse une URL interdite... ».
  • Test manquant. « autorise tout quand robots.txt est absent (404) » ajouté, comme le demande le plan.
  • Coquilles. « polices », « est GTIN », « minuscule », et la ligne vide entre les blocs /** */ et leur fonction, qui empêchait l'éditeur d'afficher la documentation au survol.

La leçon : relire tous les fichiers tapés, tests compris, avant le commit. Un test vert ne prouve pas qu'il vérifie quelque chose.

À retenir

  • Injection de dépendances. Passer fetchImpl et sleep en paramètres rend le code testable sans réseau ni attente réelle. On réutilisera ce schéma dans les adaptateurs.
  • Un refus est définitif. BlockedError n'est jamais rattrapé pour réessayer autrement. C'est la règle du projet : on ne contourne pas un marchand qui bloque.
  • Hors périmètre : la directive Crawl-delay de robots.txt est ignorée, remplacée par le délai fixe de 2 s. Les cas exotiques de robots.txt (encodage d'URL, groupes mal formés) ne sont pas gérés.
  • Suite : tâche 3, l'adaptateur Shopify (Connox et Fleux), qui utilisera createPoliteFetch et pickGtin.
